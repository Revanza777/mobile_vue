# Panduan AI Agent

## Stack
- Vue 3, Vite, Vue Router, dan AdminLTE 4.
- Gunakan Bootstrap dan Bootstrap Icons yang sudah terpasang.
- Jangan menambahkan framework UI atau dependensi tanpa alasan yang jelas.

## Struktur
- `src/components/AppLayout.vue` mengatur shell bersama seperti navbar, sidebar, dan footer.
- `src/views/` berisi halaman.
- Buat komponen terpisah untuk bagian UI yang digunakan berulang.
- Jangan menaruh isi halaman khusus di layout bersama.

## Desain UI/UX
- Perlakukan gambar desain yang diberikan sebagai referensi susunan dan alur.
- Implementasikan tampilan menggunakan pola dan kelas AdminLTE 4/Bootstrap yang tersedia.
- Pastikan halaman tetap nyaman digunakan di desktop dan ponsel.
- Jangan mengarang fitur atau data yang tidak terlihat atau diminta.

## Sebelum mengubah kode
- Periksa file dan pola yang sudah ada terlebih dahulu.
- Ubah hanya file yang diperlukan untuk tugas.
- Setelah perubahan, jalankan `npm run build` dan laporkan hasilnya.
